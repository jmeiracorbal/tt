# Code of Conduct

This is a small open source project. The expectations here are simple.

Be direct and respectful. Disagreeing with a technical decision is fine; being dismissive or hostile toward the person making it is not. If a PR gets closed or a feature request is declined, that's a technical decision, not a personal one.

Issues and PRs are the right place for project-related discussion. Keep them on topic. Off-topic threads will be closed.

If something goes wrong — a comment that crossed a line, a situation that feels off — reach out directly at [jmeiracorbal@gmail.com](mailto:jmeiracorbal@gmail.com). No committee, no process, just a conversation.
